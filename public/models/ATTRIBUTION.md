The reference organ was derived from Allen Human Reference Atlas 3D 2020, with 141 anatomical structures mirrored to form a whole brain and resized to a Visible Human body.

Modifications by this game
Display colors, scale, position and orientation changed. Meshes merged at runtime for fewer draw calls. The distributed GLB remains the original downloaded model. Original mirroring and resizing were inherited.

This model is shown as an anatomical atlas exhibit. The traversable neuronal environment, gateways, symbols, and distances are stylized game models, not an anatomical reconstruction.
